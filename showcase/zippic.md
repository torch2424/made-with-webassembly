Zippic is a free web app for compressing and converting images entirely in the browser. Codecs such as MozJPEG, WebP, and AVIF run via WebAssembly on the user's device, so photos never leave the browser.

It also includes related tools such as cropping and APNG creation, with the same local-first model.

Try it at [zippic.app](https://zippic.app).
