Vizua is a free browser-based image toolkit with 91 tools including compress, resize, convert (WebP, AVIF, PNG, JPEG), remove background, upscale, and OCR. All image processing is powered by WebAssembly and runs entirely in the browser — files never leave the user's device.

![Vizua Screenshot](https://vizua.io/og-image.png)

Vizua uses WebAssembly for computationally intensive image operations such as format conversion, lossy and lossless compression, background removal, and optical character recognition. By running everything client-side, it ensures complete privacy while delivering near-native performance. The app supports 16 languages and serves users worldwide.
