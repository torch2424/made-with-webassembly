SlingSite is a browser-based image and video compressor that resizes assets per device and converts them to modern formats, using FFmpeg compiled to WebAssembly.

Images are converted to JPG, WebP and AVIF, and video to VP9, HEVC and H.264, each generated at mobile, tablet and desktop sizes. All of this processing runs client-side via FFmpeg.wasm, so files are compressed directly in the browser and are never uploaded to a server.
